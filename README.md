# Torch — 스터디 플래너

중고등학생과 수험생이 학교·학원 일정 사이의 자습 가능 시간을 확인하고, 실천 가능한 주간 학습 목표를 세우는 한국어 웹 앱입니다. React, TypeScript, Vite로 만들었으며, 게스트의 브라우저 저장과 Firebase Google 로그인·계정별 저장을 지원합니다.

**배포된 앱:** [Torch 열기](https://torch-planner.web.app) · [보조 주소](https://torch-planner.firebaseapp.com) · Firebase Hosting

2026-10-06 기준 [Firebase 프로젝트](https://console.firebase.google.com/project/rocky-study-planner-6c82f1/overview)에 연결했습니다. Google 로그인 공급자와 승인 도메인을 설정했고, 서울 리전의 Firestore와 소유자 전용 보안 규칙을 배포했습니다. 이 작업 폴더의 `.env.local`에는 연결 설정이 들어 있습니다. 새로 복제한 작업 폴더에서는 Git에 포함되지 않는 환경 파일을 [Firebase 연결 안내](docs/FIREBASE_SETUP.md)에 따라 준비해야 합니다. 설정이 없어도 게스트 기능은 사용할 수 있습니다.

2026-10-09 앱 이름을 Torch로 바꾸고 횃불 아이콘과 함께 새 주소에 배포했습니다. PC·모바일 화면과 두 Torch 주소의 Google 로그인 화면 연결을 확인했습니다. 사용자의 실제 Google 계정으로 로그인 완료 후 저장·로그아웃·복원하는 최종 확인은 남아 있으며, 해당 동작은 로컬 Firebase 에뮬레이터로 검증했습니다.

## 실행

Node.js 22.12 이상과 npm을 준비한 뒤 프로젝트 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소로 접속합니다. 기본 주소는 `http://127.0.0.1:5173`입니다.

```sh
npm test          # 핵심 계산·저장 검증·계정 전환·저장 충돌 검증
npm run test:e2e  # 실제 브라우저에서 일정·목표·저장·모바일 검증
npm run test:firebase  # Firebase 에뮬레이터의 인증·보안 규칙·계정 UI 검증
npm run build     # TypeScript 검사 후 dist/에 배포용 파일 생성
npm run preview   # 빌드한 앱을 로컬에서 확인
```

브라우저 테스트는 Windows에서 설치된 Microsoft Edge를 사용합니다. 다른 운영체제에서는 `npx playwright install chromium`으로 테스트용 Chromium을 먼저 설치합니다. 테스트가 필요할 때 로컬 개발 서버를 자동으로 시작합니다.

Firebase 테스트는 Java 21 이상이 필요합니다. `PATH`의 Java 또는 프로젝트의 `.tools/java/<런타임>/bin`을 사용하며 실제 Google 계정이나 Firebase 프로젝트는 필요하지 않습니다. 에뮬레이터를 직접 사용하려면 별도 터미널에서 `npm run emulators`와 `npm run dev:emulator`를 실행하고 `http://127.0.0.1:5174`로 접속합니다. [에뮬레이터 실행과 테스트](docs/FIREBASE_SETUP.md#로컬-에뮬레이터와-테스트)에 자세한 설명이 있습니다.

## Firebase Hosting 배포

Firebase Hosting에 다시 배포하려면 실제 Firebase 설정이 있는 `.env.local`을 준비하고 다음 명령을 실행합니다. 배포 전에 `npm run build`가 자동 실행되며 `dist/`의 결과물을 게시합니다. 자세한 설정은 [Hosting 배포 안내](docs/FIREBASE_SETUP.md#firebase-hosting-배포)를 참고합니다.

```sh
npx firebase deploy --only hosting:rocky --project rocky-study-planner-6c82f1
```

배포 대상 `rocky`는 같은 Firebase 프로젝트의 Hosting 사이트 `torch-planner`에 연결됩니다. 앱 표시 이름은 Torch이며 횃불 아이콘을 사용합니다. 기존 데이터와의 호환성을 위해 프로젝트 ID, 인증용 `authDomain`, 브라우저 저장 키, `.env.local`과 Firestore 저장소는 그대로 사용합니다.

기존 [Eddie 주소](https://eddie-planner.web.app)와 [그 보조 주소](https://eddie-planner.firebaseapp.com), [my-rocky 주소](https://my-rocky.web.app)와 [그 보조 주소](https://my-rocky.firebaseapp.com), [프로젝트 기본 주소](https://rocky-study-planner-6c82f1.web.app)와 [그 보조 주소](https://rocky-study-planner-6c82f1.firebaseapp.com)는 게스트 자료에 접근할 수 있도록 기존 배포를 유지하며 새 주소로 자동 이동시키지 않습니다. 서로 다른 호스트의 `localStorage` 데이터는 자동으로 옮겨지지 않습니다. 게스트 자료를 옮기려면 기존 주소에서 Google 로그인 후, 계정 플래너가 비어 있을 때 **브라우저 데이터 가져오기**를 실행하고 서버 저장 완료를 확인하세요. 새 주소에서 같은 Google 계정으로 로그인하면 계정에 저장한 자료를 불러옵니다.

## 사용 방법

1. **캘린더**에서 학교 수업, 학원, 학사일정, 개인 일정을 추가합니다. 주간 시간표와 월간 캘린더를 전환하고 일정을 선택해 수정하거나 삭제할 수 있습니다.
2. **반복** 메뉴에서 반복 안 함, 매일, 매주, 매월, 주중(월~금), 맞춤을 선택합니다. 매주는 복수 요일을 선택할 수 있고, 기본 반복은 종료일을 지정할 수 있습니다. 종일 일정도 반복할 수 있습니다. 기존 반복 일정을 누르면 **적용 범위 → 이 일정만 / 전체 반복 일정**을 선택해 수정하거나 삭제합니다. ‘이 일정만’ 수정하면 선택한 날짜의 일정이 독립된 단일 일정으로 분리되고, 삭제하면 그 날짜만 반복에서 제외됩니다. 분리된 일정은 이후 전체 반복 수정·삭제의 영향을 받지 않습니다.
3. 캘린더는 별도 설정 없이 **00:00–24:00 전체 하루**를 표시합니다. 수면·식사·이동·휴식은 개인 일정으로 등록해 자습 가능 시간에서 제외합니다. 종료 시간에 자정(00:00)을 입력하면 해당 날짜의 끝인 24:00으로 처리합니다.
4. **주간 학습 계획 → 과목 관리**에서 모든 주에 공통으로 사용할 과목을 추가·수정·삭제합니다. **새 학습 목표**에서는 등록된 과목을 선택하고 학습자료와 학습 범위를 입력합니다. 목표별 예상 시간은 입력하지 않으며, 완료 여부와 전체·진행 중·완료 목록을 관리할 수 있습니다.
5. **이번 주 학습 목표 → 프린트**를 누르면 A4 미리보기가 열립니다. **과목·학습 자료·학습 범위**를 표로 확인한 뒤 **인쇄하기**를 눌러 프린터를 선택하세요. 완료 체크박스는 각 **학습 범위 텍스트 앞**에 표시됩니다. 브라우저 인쇄 설정에서 PDF로 저장할 수도 있습니다. 선택한 주의 전체 목표를 과목별로 묶어 출력하며, 같은 과목의 셀은 세로로 병합합니다. 화면의 진행 중·완료 필터와 관계없이 완료한 목표도 포함합니다. 표가 길면 머리글과 페이지 번호를 붙여 여러 장에 나누고, 다음 페이지에서도 이어지는 과목명을 다시 표시합니다. 미리보기와 인쇄는 앱의 목표·완료 상태를 바꾸지 않습니다.
6. 과목 카드 제목 옆의 **순서 이동 손잡이**를 마우스나 터치로 끌어 다른 과목 위치에 놓으면 표시 순서가 바뀝니다. 손잡이에 키보드 초점을 두고 **Space 또는 Enter → 방향키 → Space 또는 Enter**로도 이동할 수 있으며 **Escape**로 취소합니다. 과목 순서는 모든 주에 공통으로 저장되고 과목 선택 목록과 인쇄에도 반영됩니다. 필터로 숨겨진 과목과 기존 목표·일정은 보존합니다.
7. **캘린더 → 주간 시간표 → 프린트**를 누르면 선택한 주의 **A4 가로 1장 미리보기**가 열립니다. **일과 시작 시간·일과 종료 시간**을 정하면 월요일부터 일요일까지 해당 범위만 확대하여 출력합니다. 처음에는 **00:00–24:00** 전체를 사용하고, 종료 입력의 00:00은 당일 끝인 24:00입니다. 범위 밖 일정은 제외하고 경계에 걸친 일정은 보이는 부분만 배치하되 원래 시각을 표시합니다. 종일 일정은 위쪽에 유지하며 현재 체크한 종류만 인쇄합니다. 마지막 설정은 게스트의 브라우저 또는 로그인 계정에 저장되어 새로고침·재로그인·다른 기기에서 복원되고, **하루 전체**로 되돌릴 수 있습니다. 반복 일정은 해당 주의 날짜에 표시하고 겹친 일정은 나란히 배치합니다. **인쇄하기**에서 프린터 또는 PDF 저장을 선택하세요. 빈 주도 출력할 수 있으며 인쇄 범위는 실제 일정·표시 필터·학습 시간 계산을 바꾸지 않습니다.

주간 시간표의 빈 곳을 클릭하면 해당 위치를 **15분 단위**로 맞춰 새 일정의 시작 시간에 넣습니다. 예를 들어 09:37 위치를 클릭하면 09:30으로 시작하며, 종료 시간은 기본 1시간 뒤입니다. 마우스로 드래그하면 선택한 구간의 시작·종료 시간이 입력됩니다. 위로 드래그해도 이른 시각부터 정리하며, 최소 15분부터 당일 24:00까지 선택할 수 있습니다. 드래그 중에는 **(제목 없음)**과 시간 범위를 미리 보여주고, 마우스를 놓으면 입력 창이 열립니다. 옆 요일로 움직여도 처음 선택한 날짜를 유지합니다. Escape로 선택을 취소할 수 있으며, 방향키와 Enter로도 15분 단위 일정을 입력할 수 있습니다. 미리보기는 실제로 저장하기 전까지 학습 시간 합계에 포함되지 않습니다.

현재 과목들은 캘린더의 일정 종류에도 자동으로 표시됩니다. 같은 이름의 종류가 이미 있으면 기존 색상과 일정을 유지하여 연결합니다. 과목 종류에는 자물쇠가 표시되며, 이름과 삭제는 **주간 학습 계획 → 과목 관리**에서 변경합니다. 색상 변경, 표시 체크와 개별 일정의 추가·수정·삭제는 캘린더에서 사용할 수 있습니다.

과목 이름을 수정하면 모든 주의 해당 목표와 연결된 일정 종류에 함께 반영됩니다. 새 이름의 일반 종류가 이미 있으면 등록된 일정을 그 종류로 모으며, 두 종류 중 하나라도 표시 중이었다면 합친 종류를 표시합니다. 과목을 삭제할 때는 연결된 목표를 다른 과목으로 옮기거나 명시적으로 함께 삭제합니다. 캘린더 종류와 일정은 남고 과목 연결이 해제되어 일반 종류로 삭제할 수 있습니다. 모든 과목을 삭제한 상태도 저장되며, 새 목표 입력에서 과목을 다시 추가할 수 있습니다.

기본 일정 종류 외에 운동·동아리·수면 등 나만의 종류를 만들 수 있습니다. 캘린더의 **일정 종류 추가**를 누르거나 일정 입력 창의 **종류 추가**를 눌러 이름과 색상을 지정하세요. 이름은 앞뒤 공백을 정리한 뒤 1–30자이며 같은 이름은 중복 등록할 수 없습니다. 일정 작성 중 만든 종류는 바로 선택되고 작성하던 내용도 유지됩니다. 추가한 종류는 일정이 없어도 저장되며 새로고침 후 다시 사용할 수 있습니다.

왼쪽 **내 캘린더**에서 일정 종류를 체크하면 해당 종류의 일정만 주간·월간 캘린더에 표시됩니다. 체크를 해제하면 종일·반복 일정도 함께 숨겨집니다. 모든 종류를 해제할 수 있으며, 새로 만든 종류는 기본으로 체크됩니다. 체크 상태는 새로고침 후에도 유지되고 새 플래너 시작이나 예시 다시 불러오기를 하면 모든 종류가 표시됩니다. 표시 체크는 시간 계산에 영향을 주지 않습니다. **숨긴 일정도 과목 연결 여부에 따라 자습 가능 시간·계획한 학습 시간·남은 시간 계산에 포함**합니다.

두 페이지는 선택한 주를 공유합니다. 캘린더의 일정을 바꾸면 일별·주별 자습 가능 시간과 계획한 학습 시간, 남은 시간이 함께 갱신됩니다. 주간·월간 캘린더와 주간 학습 계획은 같은 계산 규칙을 사용합니다. 일정 종류의 이름이 등록된 과목 이름과 같으면 과목 일정으로 판단하며, 이름 비교는 앞뒤 공백·유니코드 NFKC·영문 대소문자를 정규화합니다. 과목 일정은 자습 가능 시간에서 차감하지 않고 계획한 학습 시간에 합산합니다. 과목 이름을 바꾸면 연결된 일정 종류 이름도 함께 바뀌므로 기존 일정의 과목 연결이 유지됩니다.

**일정 종류 색상**: 왼쪽 **내 캘린더**나 캘린더 범례에서 종류 옆 **점 세 개 옵션**을 누릅니다. 원형 팔레트를 선택하면 바로 적용되며, **+**로 원하는 색상을 직접 지정할 수도 있습니다. 과목 종류의 색상도 바꿀 수 있습니다. 변경한 색상은 주간·월간 일정과 일정 입력 창에 함께 반영되고 새로고침·계정 복원 후에도 유지됩니다. 표시 체크와 학습 시간 계산에는 영향을 주지 않습니다.

**일정 종류 삭제**: 종류의 **점 세 개 옵션 → 일정 종류 삭제**를 선택합니다. 삭제 항목은 과목에 연결되지 않은 종류에만 표시됩니다. ‘학교 수업’, ‘학원’, ‘학사일정’, ‘개인 일정’ 같은 기본 종류도 과목에 연결되어 있지 않으면 삭제할 수 있습니다. 등록된 일정이 있으면 다른 종류로 옮겨 보관하거나 해당 일정과 모든 반복을 함께 삭제할 수 있습니다. 마지막 종류에 일정이 남아 있으면 삭제 동의 체크가 필요합니다. 과목 종류는 과목 관리에서 먼저 연결을 해제해야 합니다. 종류 삭제는 학습 목표에 영향을 주지 않으며, 과목과 종류가 모두 비어 있으면 새 일정 입력에서 종류를 다시 만들 수 있습니다. 삭제 결과는 새로고침과 계정 재로그인 후에도 유지됩니다.

**맞춤**을 선택하면 ‘반복 설정’ 창에서 숫자 간격과 일·주·개월·년 단위를 정할 수 있습니다. 주 단위는 요일을 여러 개 선택하고, 월 단위는 시작일과 같은 날짜·몇 번째 요일·마지막 요일 중 선택합니다. 종료는 없음, 특정 날짜, 지정 횟수 중 하나를 고릅니다. 예를 들어 ‘2주마다 월·수요일, 10회’를 설정할 수 있습니다. 완료를 누르면 설정을 적용하고, 취소나 Escape는 변경을 버리고 작성 중인 일정으로 돌아갑니다.

## 시간 계산 기준

- 한 주는 월요일부터 일요일까지이며 날짜는 브라우저의 로컬 날짜를 따릅니다.
- **자습 가능 시간**은 하루 24시간(00:00–24:00)에서 **과목에 연결되지 않은 일정**의 점유 시간을 뺀 값입니다. 해당 일정끼리 겹치는 구간은 합쳐 한 번만 차감하며, 과목 일정은 차감하지 않습니다. 일정이 없거나 과목 일정만 있으면 하루 24시간, 한 주 168시간입니다.
- 직접 추가한 종류도 현재 과목에 연결되지 않은 일정만 자습 가능 시간에서 제외됩니다. 종류만 만들고 일정을 등록하지 않으면 자습 가능 시간은 바뀌지 않습니다. 과목을 삭제해 연결이 해제되면 남은 일정은 자습 가능 시간에서 제외됩니다.
- 수면 시간은 자동으로 제외하지 않습니다. 수면·식사·이동·휴식을 개인 일정으로 등록하면 실제로 공부할 수 있는 시간을 확인할 수 있습니다. 자정을 걸치는 수면은 23:00–24:00과 00:00–07:00처럼 두 일정으로 나누어 등록합니다.
- 과목에 연결되지 않은 **종일 일정**이 있는 날짜의 자습 가능 시간은 0입니다. 과목의 종일 일정은 자습 가능 시간을 줄이지 않고 계획한 학습 시간에 24시간을 합산합니다. 어느 종류든 종일 일정이 있으면 실제로 비어 있는 남은 시간은 0입니다.
- 반복 일정은 시작일 이후 실제 해당하는 날짜에 적용하며 종료일은 포함합니다. 주 단위 간격은 시작일이 속한 월요일 기준 주에 고정됩니다.
- 반복 횟수는 시작일 이후 실제 발생한 일정 수를 뜻합니다. 선택하지 않은 요일이나 건너뛴 달은 횟수를 소모하지 않습니다.
- 매월 같은 날짜를 선택하면 해당 날짜가 없는 달은 건너뜁니다. 예를 들어 1월 31일부터 매월 반복하면 2월을 건너뛰고 3월 31일에 반복합니다. 매년 2월 29일 반복도 윤년에만 적용합니다. 주중 반복은 공휴일 여부와 관계없이 월요일부터 금요일까지 적용합니다.
- **계획한 학습 시간**은 선택한 주의 캘린더에서 과목 이름과 같은 일정 종류의 점유 시간을 합산한 값입니다. 일별·주별 전체 합계와 과목별 합계를 표시하며, 같은 날짜의 겹친 구간은 한 번만 계산합니다. 각 과목에서도 겹친 구간은 한 번만 계산하므로, 서로 다른 과목의 일정이 겹치면 과목별 시간의 합은 전체 합계보다 클 수 있습니다.
- 숨긴 일정과 반복 일정도 동일하게 합산합니다. 과목에 해당하는 종일 일정은 하루 24시간으로 계산합니다. 다른 종류의 일정과 겹쳐도 과목 일정의 계획 시간은 그대로 계산합니다. 목표가 없는 과목의 일정도 포함하며, 목표 추가·수정·완료·삭제와 과거 목표의 예상 시간은 합계에 영향을 주지 않습니다.
- **더 계획할 수 있는 시간**은 하루 24시간에서 과목 일정을 포함한 **모든 일정의 점유 구간을 합쳐 제외한 실제 빈 시간**입니다. 자습 가능 시간에서 계획한 학습 시간을 단순히 빼지 않으므로, 과목 일정과 다른 일정이 겹쳐도 중복 차감하지 않습니다. 예를 들어 일반 일정이 09:00–11:00, 과목 일정이 10:00–12:00이면 그날 자습 가능 시간은 22시간, 계획한 학습 시간은 2시간, 남은 시간은 21시간입니다.
- 내부 시간 계산과 저장은 정수 분 단위로 처리합니다.

목표는 주 단위로 관리되며 특정 요일이나 시간대에 배정되지는 않습니다. 요일별 자습 가능 시간을 참고해 주간 목표의 전체 학습량을 정할 수 있습니다.

## 예시와 데이터 저장

과목 목록은 선택적 `subjects` 필드로 저장합니다. 이 필드가 없는 이전 데이터에는 기본 과목과 기존 모든 목표의 과목을 합쳐 추가하며, 명시적으로 저장된 빈 목록은 복구하지 않습니다. 기존 목표의 `estimatedMinutes`는 읽기 호환성을 위해 보존하지만 계산에 사용하지 않고 새 목표에는 저장하지 않습니다.

불러온 데이터를 검증한 뒤 과목에 대응하는 일정 종류가 없으면 자동으로 추가합니다. 기존 종류와 필터는 유지하며 같은 데이터를 다시 읽어도 동일한 종류 ID를 사용합니다. 직접 추가하는 종류 이름은 30자까지, 과목에서 연결된 종류 이름은 과목과 동일하게 40자까지 지원합니다. 과목을 삭제해 일반 종류로 바뀌어도 기존 이름과 일정은 보존합니다.

첫 실행에는 현재 주를 기준으로 만든 **가상의 예시 일정과 학습 목표**가 표시됩니다. 화면의 `새 플래너 시작`으로 데이터를 비우거나 `데이터 관리`에서 예시를 다시 불러올 수 있습니다. 기존 데이터를 교체하기 전에 확인 창이 표시됩니다.

게스트의 일정 종류, 과목 목록, 캘린더 체크 상태, 일정, 목표, 예시 여부는 `localStorage`의 `chagok-planner-v1` 키에 저장 형식 버전 3으로 자동 저장됩니다. 앱 이름 변경 전의 데이터도 불러올 수 있도록 기존 저장 키를 유지합니다. 버전 1·2의 데이터는 기존 일정과 목표를 그대로 보존하여 자동 변환하고 기본 일정 종류를 추가합니다. 버전 1의 과거 활동 시간 설정은 제거합니다. 캘린더 체크 상태가 없는 기존 데이터는 모든 종류를 표시합니다. 같은 브라우저와 같은 주소로 다시 접속하면 데이터를 불러옵니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 접속 주소 변경은 게스트 데이터와 아직 서버에 저장하지 못한 변경사항에 영향을 줄 수 있습니다.

Firebase를 연결한 후 **Google 로그인**을 선택하면 계정 전용 플래너를 사용합니다. 새 계정은 빈 플래너로 시작하며 게스트의 데이터는 별도로 유지됩니다. 직접 작성한 게스트 데이터가 있고 계정 플래너가 비어 있으면 **브라우저 데이터 가져오기**로 옮길 수 있습니다. 가상의 예시 데이터는 자동으로 가져오지 않습니다.

로그인 중 수정한 내용은 Firestore의 `users/{uid}/planner/main`에 자동 저장됩니다. **로그아웃해도 서버 데이터는 삭제되지 않으며**, 같은 계정으로 다시 로그인하거나 다른 기기에서 로그인하면 불러옵니다. 로그아웃한 화면에는 기존 게스트 플래너가 표시됩니다. 계정 데이터가 게스트나 다른 계정의 플래너에 섞이지 않도록 저장 위치를 분리합니다.

미저장 변경사항은 `rocky-planner-account:{uid}`에 계정별로 보관하며, 같은 계정으로 다시 로그인하면 서버 저장을 재시도합니다. 로그인·새로고침·계정 메뉴의 **지금 동기화**에서 최신 서버 데이터를 확인합니다. 다른 기기의 변경을 실시간으로 수신하지는 않습니다. 두 기기의 수정이 충돌하면 자동 덮어쓰기를 멈추고, 현재 내용을 백업한 뒤 **서버 데이터 불러오기**로 최신 내용을 선택할 수 있습니다. 플래너는 한 문서로 저장하며 앱에서 JSON 크기를 900,000바이트까지 허용합니다.

저장 데이터가 손상되었거나 형식이 맞지 않으면 오류를 알리고 자동 저장을 중단하여 원본을 덮어쓰지 않습니다. 저장 공간이나 브라우저 제한으로 저장에 실패해도 화면에서 안내합니다. 새 플래너 시작 확인 창과 저장 오류 안내에서 현재 화면의 데이터를 JSON 파일로 백업할 수 있습니다. 첫 버전에는 백업 파일을 가져오는 UI가 없습니다.

일정은 같은 날짜의 00:00에 시작하거나 24:00에 종료할 수 있습니다. Google 로그인은 Torch의 계정 저장용이며 실제 Google Calendar 연결, 알림, 다음 날까지 이어지는 단일 일정은 지원하지 않습니다. 반복 일정의 수정·삭제 범위는 기본으로 ‘이 일정만’이 선택되며, ‘전체 반복 일정’으로 바꿀 수 있습니다.
